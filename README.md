# Turtle Springboard Math Game

A playful browser-based math game where a cheerful turtle springs onto the correct answer board to solve quick addition challenges.

## Overview

This project is a small front-end game built with HTML, CSS, and JavaScript. Players are shown a simple emoji-based addition problem, then choose the correct answer from four floating boards. Correct answers trigger confetti and happy sound effects, while incorrect answers cause the turtle to bounce away with a playful "BOO!" reaction.

## Features

- Randomized emoji addition puzzles
- Four answer choices per round
- Animated turtle and springboard interactions
- Sound effects and adjustable volume control
- Bright, kid-friendly game styling
- No build step required

## Project Files

- `index.html` – game structure and UI
- `style.css` – visual styling and animations
- `script.js` – game logic, audio, and interactions

## How to Run

1. Open the project folder in your browser, or serve it locally.
2. Start a simple local web server:

```bash
python -m http.server 8000
```

3. Visit `http://localhost:8000` in your browser.

## Gameplay

- A math problem appears using emoji groups, such as `🍬 + 🍬`.
- Select the correct sum from the four answer boards.
- Each correct answer advances to the next round.
