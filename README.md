# Turtle Springboard Math Game

A cheerful browser-based math game where a friendly turtle jumps to the correct answer board to solve quick addition challenges.

## Overview

Turtle Springboard Math Game is a fun front-end project built with HTML, CSS, and JavaScript. Players are shown a simple emoji-based addition problem and must choose the correct sum from four floating answer boards. Each round brings a new randomized puzzle, with animated feedback, sound effects, and bright, kid-friendly visuals.

## Features

- Randomized emoji addition questions
- Four possible answer choices per round
- Animated turtle movement and springboard reactions
- Positive and negative feedback effects
- Adjustable volume control
- Bright, playful visual design for children
- No build tools or dependencies required

## Project Structure

- `index.html` — game layout and UI structure
- `style.css` — game styling, animations, and layout
- `script.js` — game logic, sound effects, and interactions
- `README.md` — project overview and usage instructions

## How to Run

You can either open `index.html` directly in a browser or run a local web server.

### Option 1: Open directly

1. Open `index.html` in your browser.
2. Start playing immediately.

### Option 2: Run a local server

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## How to Play

1. A math question appears using emoji groups, such as `🍬 + 🍬`.
2. Look at the equation and calculate the total.
3. Click the answer board with the correct value.
4. If you are right, the turtle celebrates and a new question appears.
5. If you are wrong, the turtle gets tossed and the next question loads.

## Controls

- Click any answer board to submit your choice.
- Use the volume slider in the top-right corner to adjust sound.
